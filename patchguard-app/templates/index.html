Detector output (person class)

StageWhat happens
1. LocaliseSobel gradient magnitude → local density ρ via a win×win box filter → flag pixels with ρ > μρ + kσρ, drop blobs smaller than the minimum area, dilate.
2. NeutraliseReplace masked pixels with a normalised-convolution blur of surrounding clean pixels (Gaussian σ).
3. AlertDetect on raw and sanitised frames; if the sanitised frame reveals more people than the raw one, raise a security alert.

The sticker simulator here is a high-frequency stand-in. To use your real learned patch, run patchguard_demo.py and keep results/patch.png – the app picks it up automatically. A synthetic sticker cannot fool YOLO the way the optimised one does, so the alert fires only when the detector is actually affected.
